# Support

## Support model

This project is maintained as an open source effort by a single maintainer within the Dynatrace open source organization.
Support is provided on a best-effort basis only. There are no guaranteed response or resolution timelines, and issue prioritization is at the maintainer's discretion.
Community contributions (bug fixes, docs improvements, and reproductions) are welcome and can help speed up resolution.

## Supported Versions

- `main` branch: supported
- Latest release: supported
- Older releases: best-effort only

## How to Get Help

Please use GitHub Issues for:
* bug reports
* feature requests
* general questions related to this repository

If you believe you have found a security issue, do not file a public issue. Follow the instructions in SECURITY.md.

## Commercial support

This repository is not covered by standard Dynatrace commercial support.
